4Tab 切换逻辑

Tab 状态: useState<"tasks" | "files" | "git">("tasks")
       │
       ▼
onClick={() => setActive(id)}
       │
       ├── "tasks" → CompactTaskList + ContextTabPanel
       ├── "files" → FileTree
       └── "git"   → GitPanel

git 状态由 useGitStore 管理：
       ├── repoStatus.isGitRepo
       └── repoStatus.clean
       │
       └── clean=false → Git Tab 显示 amber 圆点徽章

5关键交互

交互行为
切换 Tasks / Files / Git本地 useState 切换，无 URL 同步
Tasks 按会话隔离tasks.filter(t => t.sessionId === currentId)
任务状态变化自动滚底新任务 / running→done 切换时
任务删除hover 出现 × 按钮，tasksStore.removeTask
上下文 Tab 文件点击onFileClick → App.tsx 打开 CodeViewerModal
文件树展开点击 chevron / 文件夹图标，懒加载子节点
文件树文件点击唤起 CodeViewerModal（与上下文 Tab 共用）
Git 暂存切换点击复选框切换暂存状态（IDEA 行为）
