3状态点语义

会话项左边的状态点指示会话当前状态，对应三种视觉表现。

状态视觉含义
运行中 isRunning该会话正在流式输出，brand 色旋转环
新结果 hasNewResult会话有未读新结果，brand 色弱化圆点
当前激活 active用户当前正在查看的会话
静态其他历史会话，muted 色小圆点

4分组数据流

stores/chat.sessions: Record<sid, Session>
       │
       ▼  useMemo
groups = { homeItems, workspaces[] }
       │
       ├── homeItems    = sessions.filter(s => s.workspacePath == null)
       │                       .sort(by createdAt desc)
       │
       └── workspaces[] = Map<workspacePath, Session[]>
                                .sort(by latestAt desc)

       ▼ 渲染
SessionGroup (Home) ──── 默认展开
SessionGroup (workspace1)
SessionGroup (workspace2)
   ...
       │
       └── 每个分组内：SessionItem 列表，按 createdAt 倒序
