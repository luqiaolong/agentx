0项目总览

AgentX 桌面应用 Tauri 2.x + React 18 的整体 UI 结构。本蓝图把 UI 按空间位置拆分为 4 个主区域（A 顶部 title bar / B 左侧会话列表 / C 中央聊天工作区 / D 右侧工作区面板），共 9 个模块详细设计文档。
