6通用术语（必读）

所有 AI 代理讨论 UI 时必须使用以下术语，避免"左边""右边"等模糊描述。

术语English定义
场景 Tab（Scene Tab）Scene Tab顶部 title bar 的 work / coding 切换
agent 类型选择器Mode Toggle输入框旁的 popover，按场景过滤
会话列表 / 会话项Session List / Item左侧栏的历史会话
工作区Workspace右侧面板统称
执行轨迹Execution Trace消息中展示模型推理 + 工具调用的卡片组
路由决策Router Decision分类卡 (ClassificationCard)
子代理委派Sub-agent DelegationDelegationCard，标记"由 XX 子代理执行"
工具调用Tool Call模型调用工具的执行轨迹卡片
权限模式Permission Mode会话级字段，影响工具调用是否触发审批
开发模式Dev Mode后端以终端方式启动的开关
