3场景 Tab 状态展示

场景 Tab 切换会联动修改 agent_mode，不同的 mode 对应不同的 agent 类型选项（详见 M.04 输入区）。

Work 场景
→ agent_mode = work
Coding 场景
→ agent_mode ∈ {coding, coding_team}

4交互逻辑（场景 Tab）

用户点击 Scene Tab
       │
       ▼
applySceneChange(targetScene, currentMode)  ← stores/scene.ts
       │
       ├── targetScene === "work"
       │      └── return "work"           (强制)
       │
       └── targetScene === "coding"
              ├── currentMode === "work"  → return "coding"     (work → coding 升级)
              └── currentMode ∈ {coding, coding_team} → return currentMode (保持)

       ▼
setAgentMode(newMode)  ← stores/agentMode.ts (zustand)
       │
       ▼
组件订阅变化 → 触发 UI 重渲染
       │
       ▼
ModeToggle 显示对应场景的 agent 类型列表

5设计规范

属性规范
高度h-10 = 40px
背景rgba(255,255,255,0.85) + backdrop-filter: blur(12px) (glass-card)
下边框1px solid var(--border)
拖拽整个 title bar 是 app-drag-region（按钮内部 app-no-drag 排除）
双击行为onDoubleClick={() => void maximize()}
场景 Tab 圆角rounded-md (8px)
场景 Tab 选中色bg-brand-700 / text-brand-200
关闭按钮 hoverhover:bg-rose-700 hover:text-brand-200
