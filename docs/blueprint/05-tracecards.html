1设计原则

执行轨迹卡片族用于展示模型的推理过程 + 工具调用细节，与聊天主内容（用户 / 助手对话文本）必须视觉分离，避免干扰主内容阅读。

4parts 配对规则

后端 SSE 事件流中的 part 类型，前端通过 buildRenderItems 配对合并。

message.parts: MessagePart[]
       │
       ▼ buildRenderItems()
       │
       ├── Pass 1: 收集
       │     ├── toolResults: Map<id, tool-result part>
       │     ├── toolCallIds: Set<id>
       │     └── toolCalls: Map<id, tool-call part> (去重)
       │
       ├── Pass 2: 配对
       │     ├── tool-call + 配对 tool-result → PairedToolCall (complete/error)
       │     ├── tool-call 无配对 → PairedToolCall (running)
       │     ├── tool-result 孤儿 → OrphanToolResult (兜底)
       │     ├── text → textItem (追加到末尾)
       │     └── classification / delegation / reasoning / team → items
       │
       └── Pass 3: 折叠
             ├── 连续 ≥ 3 个相同 toolName → tool-call-group
             └── 其余保持原样

       ▼
   RenderItem[]
