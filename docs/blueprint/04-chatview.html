4消息流渲染机制

messages: ChatMessage[]
       │
       ▼ AssistantUIThread
       │
       ├── 有 parentRef → VirtualizedThread
       │     ├── useVirtualizer (overscan=5)
       │     ├── estimateSize = measureElement 实际高度
       │     └── absolute + translateY 定位
       │
       └── 无 parentRef → 普通列表 (测试环境)

单条消息分发：
       ├── role=user  → UserMessageBubble
       ├── role=tool  → ToolSystemMessage
       └── role=assistant → AssistantMessageParts
                  ↓
       buildRenderItems(parts) 配对 + 折叠
                  ↓
       SubAgentGroup (含 delegation)
       或独立卡片 (无 delegation)

5关键交互

交互行为
↑ 键（输入框为空）快速编辑上一条用户消息（参考 Cursor）
Enter（输入框）发送消息
Shift+Enter换行
/ 触发打开 CommandPicker（命令 + 技能）
@ 触发（仅 work）打开 MentionPicker（子代理列表）
拖拽文件到输入区保存为 <file>rel</file> 标签附在末尾
流式期间切换会话禁用 + alert
发送按钮 状态Send → Pause（流式）→ Resume（暂停）→ Send
