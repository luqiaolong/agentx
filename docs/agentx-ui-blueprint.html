4场景 / agent 类型 / mode 派生关系

后端契约 agent_mode 是单字段（work / coding / coding_team），前端 UI 用场景 + agent 类型两层展示，关键实现见 frontend/renderer/stores/scene.ts。

┌────────────────────────────────────────────────────────────┐
│  Scene (UI 第 1 层 · 顶部 title bar)                         │
│  ┌───────────────┐    ┌───────────────┐                      │
│  │     Work      │    │    Coding     │                      │
│  └───────────────┘    └───────────────┘                      │
│         │ derive              │ derive                       │
│         ▼ mode==='work'      ▼ mode∈{coding, coding_team}   │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ Agent Type (UI 第 2 层 · 输入框旁 ModeToggle)            │ │
│  │ Work scene → [Work]                                     │ │
│  │ Coding scene → [Coding Agent] [Coding Team]            │ │
│  └────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
                       │ 写入
                       ▼
            stores/agentMode (zustand)
            field: mode ∈ {work, coding, coding_team}
                       │ 通过 ChatRequest 发送
                       ▼
              后端 router.run_router(mode)

联动规则（stores/scene.ts）

操作当前 mode触发条件新 mode
点击 Work Tab任意用户点击场景 tab → "work"work（强制）
点击 Coding Tabworkwork → coding 升级coding（默认 Expert）
点击 Coding Tabcoding保持coding
点击 Coding Tabcoding_team保持coding_team

6关键交互规范

从代码注释和 OpenSpec 中提炼的 UI 行为约束，所有 AI 代理在讨论前端时应遵守。

交互规范
场景 Tab 切换scene=work → 强制 mode=work；scene=coding → 保留 mode（work→coding 升级）。见 stores/scene.ts。
agent 类型选择器位置：输入框旁的 popover，按当前 scene 过滤。Work scene 仅显示 [Work]，Coding scene 显示 [Coding Agent] [Coding Team]。
命令面板输入 / 触发（含行首或紧跟空白后），↑↓ 导航，Enter 选中，Esc 关闭。
@mention 面板输入 @ 触发，仅 work 模式有效，coding 模式自动剥离标记。
用户消息编辑hover 用户消息 → 显示 ✏ 按钮 → 点击进入就地编辑 → Enter 提交 / Esc 取消（流式期间禁用编辑）。
执行轨迹卡片默认折叠，delegation 容器包裹执行轨迹（reasoning + tool-call / tool-call-group）。连续 ≥3 个相同 tool 合并为 ToolCallGroup。
路由决策可视化路由分类通过 ClassificationCard 独立卡片展示，位于 delegation 之上，包含分类原因。
危险工具审批ApprovalDialog，dangerous_tool 二按钮（拒绝 / 批准）+ 可选倒计时自动批准；directory_extension 三按钮（拒绝 / 本次允许 / 会话内允许）。
workspace 绑定会话级字段 workspacePath，未设置时回退 Home（桌面目录）。切换会话自动切换 workspace。
权限模式会话级 permissionMode ∈ {standard, acceptEdits, bypassPermissions}，影响工具调用是否触发审批。
开发模式sidebar 底部开关，开启后 Rust 用 PowerShell 启动 Python 后端保留控制台窗口（方便看日志），重启后端生效。
